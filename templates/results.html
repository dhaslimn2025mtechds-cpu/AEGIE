Prototype Interpretation

AEGIE demonstrates an end-to-end CPU-compatible technical interview analysis pipeline. A real voice response is recorded, transcribed using NVIDIA Parakeet, converted into measurable speech features, compared with reference knowledge using MiniLM, processed through the agent architecture, and displayed as transparent evidence.

The current DEVELOPMENT interview uses a fixed five-question sequence for reproducible software testing. Adaptive difficulty and calibrated score-based feedback remain gated until proper human validation is available.
