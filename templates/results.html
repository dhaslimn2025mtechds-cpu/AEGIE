Prototype Interpretation

AEGIE demonstrates an end-to-end technical interview analysis pipeline on CPU-compatible hardware. A genuine voice response is recorded, transcribed using Parakeet, converted into objective speech features, compared with researcher-created reference answers using MiniLM, processed through the agent architecture, and presented as transparent evidence.

The DEVELOPMENT question sequence is intentionally fixed for reproducible software testing. Adaptive difficulty and calibrated feedback remain gated until an approved validation study provides the evidence needed to justify those outputs.
